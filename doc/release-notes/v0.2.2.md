YetEase Music 0.2.2：修复 Android 版无法联网。

## 修复

- **Android**：0.2.1 能正常启动，但所有网络请求都会失败（系统证书校验组件需要先经 JNI 初始化）。现在 Android 上改用内置的根证书库，登录、搜索恢复正常

## 已知问题

- **Android 版本仍然无法出声**：歌曲能加进播放栏，但一直停在缓冲中。已在 [0.2.3](https://github.com/Gloridust/YetEaseMusic/releases/tag/v0.2.3) 修复，请直接安装 0.2.3。
- 更正：本说明最初写了「Android 前后台播放已在模拟器上验证」，实际当时的测试并未通过，特此更正并致歉。

YetEase Music 0.2.2 fixes networking on Android: 0.2.1 launched correctly but every HTTPS request failed because the platform certificate verifier needs JNI initialisation. Android now uses bundled webpki root certificates. Known issue: audio playback on Android still did not work in this version (fixed in 0.2.3). An earlier version of these notes wrongly claimed Android playback had been verified.
