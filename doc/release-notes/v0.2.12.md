YetEase Music 0.2.12：修复安卓上顶栏被状态栏盖住、登录和设置点不了的问题。

## 修复

- **安卓顶栏落进状态栏**（[#21](https://github.com/Gloridust/YetEaseMusic/issues/21)）：在部分安卓手机上（如 Redmi K50 / HyperOS 2），界面顶栏会画到系统状态栏底下，被时间和电量图标盖住，右上角的登录（头像）和设置按钮点不到。现在顶栏、侧边菜单、播放队列和播放页都会让开状态栏和刘海；底部播放条也会让开手势条，按钮不再贴着屏幕底边。状态栏和导航栏的图标颜色跟随应用的浅色 / 深色主题

桌面端没有变化。

## 升级

**安卓**：目前安卓安装包还没有固定的发布签名，每个版本的签名都不一样，系统不允许直接覆盖安装。请先卸载旧版，再安装下面的 APK。卸载会清掉登录状态，装好后重新扫码登录即可。之后会换成固定签名，以后就能直接覆盖升级。

**桌面端**：已经装了 0.2.8 及以后版本的话，应用启动后会提示这个版本，点「立即更新」即可（deb 会弹出系统授权框）；也可以在 *设置 → 关于* 里手动「检查更新」。这个版本桌面端没有变化，不升级也可以。

YetEase Music 0.2.12 fixes the Android layout: on some phones the top bar was drawn under the system status bar, which covered the login and settings buttons so they could not be tapped. The top bar, side menu, queue and now-playing page now stay clear of the status bar and display cutout, and the player bar stays clear of the gesture bar. Desktop builds are unchanged. Android APKs are not yet signed with a fixed release key, so Android cannot install this version over an older one: uninstall the old version first (you will need to log in again), then install the APK.
