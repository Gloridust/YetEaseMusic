YetEase Music 0.2.0：全平台安装包，功能补齐。直连网易云官方接口，不经过第三方服务器，没有广告。

## 下载

| 平台 | 文件 |
|---|---|
| Ubuntu / Debian | `yetease-music_0.2.0_amd64.deb`：双击安装，或 `sudo apt install ./yetease-music_0.2.0_amd64.deb` |
| 其他 Linux | `yetease-music-0.2.0-linux-x86_64.tar.gz`：解压后运行 `./install.sh` |
| Windows 10 / 11 | `yetease-music-0.2.0-windows-x64-setup.exe`，免安装版为 `…-portable.zip` |
| macOS | `yetease-music-0.2.0-macos-universal.dmg`（未签名，首次打开请右键选「打开」） |
| Android | `yetease-music-0.2.0-android-universal.apk`（不确定架构就选它） |
| 命令行 | `yetease-cli-0.2.0-*`（deb 已自带） |

## 新功能

- **系统媒体控制**：Linux MPRIS（键盘媒体键、GNOME 顶栏与锁屏控件）、Windows SMTC、macOS 正在播放
- **Android 后台播放**：通知栏 / 锁屏控件，蓝牙耳机与车机方向盘按键
- **逐字歌词**：卡拉 OK 式逐字高亮，翻译按时间对齐
- **桌面歌词**：透明悬浮窗，逐字填充，可锁定、调字号；播放栏「词」按钮开关
- **专辑页、歌手页**，歌手名与专辑名一点即达；**歌单广场**（热门分类）与**排行榜**
- **搜索**分单曲 / 歌单 / 专辑 / 歌手
- 播放页「歌词 / 相似推荐」切换；收藏专辑、关注歌手、收藏歌单；歌单页「下载全部」
- **终端界面**：`yetease tui`
- **日志导出**：设置 → 反馈 → 导出日志（自动抹掉登录凭据），或 `yetease export-logs`
- 图片磁盘缓存；音乐缓存上限可设（默认 2GB），超出自动淘汰最旧的；设置页可查看占用并清除

## 修复与改进

- 深色播放栏里缓冲条盖住播放进度、按钮悬停出现白块
- 网络抖动时自动重试
- 没有 D-Bus 会话总线（SSH、容器）时命令行版不再崩溃

## 已知限制

- GNOME（Wayland）不允许应用自己置顶窗口：在桌面歌词上按 Alt+Space，选「置顶」
- 收藏歌单需要网易云的易盾人机校验，原生客户端可能被拒（会明确提示）；取消收藏不受影响
- Android 版尚未在实体车机上充分测试，欢迎反馈

YetEase Music 0.2.0 – installers for every platform and a feature-complete client. Linux (.deb and tarball), Windows (installer and portable), macOS (universal dmg, unsigned) and Android (APK) packages are attached. Highlights: system media controls, Android background playback, word-by-word and desktop lyrics, album / artist / chart pages, a terminal UI and redacted log export.
