YetEase Music 0.2.13：修复歌曲无法播放、提示「api error -460: 检测到您的网络环境存在风险」的问题。**所有平台都建议尽快升级。**

## 修复

- **播放报 -460「网络环境存在风险」**：最近网易云收紧了风控，获取歌曲播放链接时会检查客户端身份是否前后一致。之前的版本在这类请求里自称 iPhone 客户端，设备信息却写的是 Windows 电脑，两者对不上，于是每首歌都被拒绝播放（搜索、歌词、评论不受影响）。现在这类请求统一以电脑客户端身份发出，歌曲恢复正常播放。登录与否都受影响，与账号、网络环境无关

## 升级

**桌面端**：已经装了 0.2.8 及以后版本的话，应用启动后会提示这个版本，点「立即更新」即可（deb 会弹出系统授权框）；也可以在 *设置 → 关于* 里手动「检查更新」。

**安卓**：0.2.12 及以后的版本可以直接覆盖安装或应用内更新；还在用 0.2.11 及更早版本的话，需要先卸载旧版再安装（详见 [0.2.12](https://github.com/Gloridust/YetEaseMusic/releases/tag/v0.2.12)）。

YetEase Music 0.2.13 fixes songs failing to play with "api error -460: network environment at risk". NetEase recently tightened its risk checks on song URL requests, and earlier versions identified as an iPhone client while sending Windows device details, so every song was refused (search, lyrics and comments were unaffected). These requests now consistently identify as the desktop client and playback works again, whether or not you are logged in. All platforms should update. Desktop users on 0.2.8 or later will be offered the update in the app; Android users on 0.2.12 can install over it, while older Android installs need to be uninstalled first.
