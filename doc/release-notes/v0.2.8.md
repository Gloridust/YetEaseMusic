YetEase Music 0.2.8：应用内检查更新，一键升级。

## 新功能

- **应用内更新**：启动时自动检查新版本（可在 *设置 → 关于* 里关闭，也可以手动「检查更新」），弹窗里直接看这期间每个版本的更新日志
- **一键更新，保持原来的安装方式和位置**：
  - deb：下载新的 deb，经系统授权框用 apt 安装，装完自动重新打开
  - AppImage：下载新的 AppImage，原地替换当前文件（路径和文件名不变），重新打开
  - 压缩包（`install.sh` 安装）：下载新压缩包并装回 `~/.local/opt/yetease-music`
  - Windows 安装版：退出后静默安装新版本，装完自动重新打开
  - macOS：下载并打开 dmg，拖进「应用程序」替换即可
  - Android：下载对应架构的 apk，调起系统安装器
  - Flatpak、Windows 免安装版：提示更新方式或打开发布页
- 安装包下载后会对照发布里的 `SHA256SUMS` 校验，不一致就不安装
- 可以「跳过此版本」，自动检查时不再提示它
- Android 上「提交 Issue」「项目主页」等链接现在能正常打开

## 说明

- 应用内更新从本版开始提供，从旧版本升级到 0.2.8 仍需手动下载一次
- Android 的旧版本每次发布的签名都不一样，系统可能提示与已安装的应用冲突，需要先卸载旧版

YetEase Music 0.2.8 adds in-app updates: the app checks for new versions at startup (or on demand under Settings → About), shows the changelog of every version since yours, and updates with one click while keeping your install method and location – deb via apt with a system authorization prompt, AppImage replaced in place, the tarball install reinstalled to the same folder, and the Windows installer run silently, each followed by an automatic restart. macOS downloads and opens the dmg, Android hands the matching apk to the system installer, and Flatpak or portable installs are pointed to the right place. Downloads are verified against SHA256SUMS, and a version can be skipped. Links now open on Android too.
