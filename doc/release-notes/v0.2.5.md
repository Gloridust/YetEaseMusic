YetEase Music 0.2.5：系统托盘，关闭窗口后继续播放。

## 新增

- **系统托盘**（[#3](https://github.com/Gloridust/YetEaseMusic/issues/3)）：关闭主窗口后程序留在托盘里继续播放。托盘菜单可以显示主窗口、播放 / 暂停、切歌、退出，鼠标悬停显示当前歌曲
  - Linux：KDE、Xfce、Cinnamon 等直接可用；GNOME 需要 AppIndicator 扩展（Ubuntu 默认已装）。没有托盘的桌面上关闭窗口会直接退出
  - Windows：右下角通知区域图标
  - macOS：关闭窗口后留在程序坞，点图标重新打开
  - 不想要这个行为：设置 → 窗口 → 关闭「关闭窗口时最小化到托盘」
- **只运行一个实例**：窗口收进托盘后，再从应用菜单打开会直接显示原来的窗口，不会再开一个播放器
- README 补充了 [FlatPark](https://flatpark.org/apps/io.github.gloridust.yetease/) 上的 Flatpak 安装方式（[#4](https://github.com/Gloridust/YetEaseMusic/issues/4)）

---

YetEase Music 0.2.5 adds a system tray: closing the main window keeps the music playing, and the tray menu can bring the window back, play / pause, skip and quit. It works on KDE, Xfce and Cinnamon out of the box and on GNOME with the AppIndicator extension; Windows gets a notification-area icon, and on macOS the app stays in the Dock. Starting the app again now brings back the existing window instead of launching a second player. The behaviour can be turned off under Settings → Window.
