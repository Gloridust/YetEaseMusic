YetEase Music 0.2.4：新增 AppImage 单文件版，为上架 Flathub 做准备。

## 新增

- **AppImage**：`yetease-music-0.2.4-x86_64.AppImage`，任意 Linux 下载后加执行权限即可运行，不用安装，也不需要 Flatpak。附带 `.zsync`，AppImageUpdate、Gear Lever 等工具可以增量升级
- Flatpak 打包所需的 AppStream 元数据与构建清单（Flathub 上架审核中）

## 变更

- Linux 版应用 ID 由 `io.github.gloridust.yetease` 改为 `io.github.gloridust.YetEaseMusic`（Flathub 要求 ID 对应真实的仓库地址）。用 deb 升级或重新运行压缩包里的 `./install.sh` 都会自动换成新的菜单项，登录状态、设置与缓存不受影响。Android、Windows、macOS 不受影响

## 下载

| 平台 | 文件 |
|---|---|
| Ubuntu / Debian | `yetease-music_0.2.4_amd64.deb` |
| 任意 Linux（免安装） | `yetease-music-0.2.4-x86_64.AppImage` |
| 其他 Linux | `yetease-music-0.2.4-linux-x86_64.tar.gz`（解压后运行 `./install.sh`） |
| Windows 10 / 11 | `yetease-music-0.2.4-windows-x64-setup.exe`，免安装版为 `…-portable.zip` |
| macOS | `yetease-music-0.2.4-macos-universal.dmg`（未签名，首次打开请右键选「打开」） |
| Android | `yetease-music-0.2.4-android-universal.apk` |

完整功能介绍见 [0.2.0](https://github.com/Gloridust/YetEaseMusic/releases/tag/v0.2.0)。

---

YetEase Music 0.2.4 adds a single-file AppImage that runs on any Linux distribution without installation, with a `.zsync` file for delta updates, plus the AppStream metadata and build manifest for the upcoming Flathub release. The Linux app ID changes from `io.github.gloridust.yetease` to `io.github.gloridust.YetEaseMusic`; upgrading via the .deb or re-running `./install.sh` switches the menu entry automatically, and your login, settings and cache are kept.
